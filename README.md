## 📝 자기소개
**"시작은 미약하나 끝은 창대하리라."**  
특전사 출신이라는 독특한 이력을 바탕으로, 데이터 분석가라는 새로운 목표를 향해 꾸준히 나아가고 있는 김도현입니다.  
해외 파병이라는 목표를 이루기 위해 특전사에 자원입대해 부사관으로 임관했고, 각종 교육에서 1등으로 수료하며 목표 달성을 위한 열정과 끈기를 증명했습니다.  
UN 평화유지활동의 일환으로 레바논 파병 임무를 수행하며 체력과 인내심은 물론, 체계적이고 계획적인 업무 능력을 길렀습니다.  
전역 후 한국정보통신기술협회(TTA)에서 행정 및 사업관리 업무를 수행하며 조직 내 협업 역량을 키웠고, 반복되는 업무를 자동화하는 프로그램을 직접 구현해 효율성을 높였습니다.  
이를 계기로 데이터 기반 문제 해결에 매력을 느꼈고, 본격적으로 데이터 분석가로의 전환을 결심했습니다.  
이후 프로그래머스 데이터 분석 데브코스를 수료하며 Python, SQL, Pandas 등을 활용한 실전 프로젝트를 수행하였습니다.  
대표적으로는 시계열 지표를 활용한 **S&P500 지수 방향 예측 모델 개발**, 카드사 데이터를 기반으로 한 **고객 세분화 및 수익 모델 최적화 프로젝트** 등이 있으며, 데이터 수집부터 전처리, 모델링, 시각화 및 ROI 분석까지 전 과정을 경험했습니다.  
또한, 챗GPT를 비롯한 다양한 도구를 적극적으로 활용하며 분석가로서의 문제 해결 역량을 키워가고 있습니다.    
**데이터 기반 의사결정에 실질적으로 기여하는 분석가**가 되는 것을 목표로, 빠른 학습력과 끈기 있는 실행력으로 팀에 기여하겠습니다.
