## 📝 자기소개
**"시작은 미약하나 끝은 창대하리라."**  
특전사 출신이라는 독특한 이력을 바탕으로, 데이터 분석가의 꿈을 향해 한 걸음씩 나아가고 있는 김도현입니다.  
작은 출발점에서도 꾸준한 노력과 열정으로 성과를 만들어내겠다는 신념으로 커리어 전환을 준비해왔습니다.
해외 파병이라는 목표를 이루기 위해 특전사에 자원입대하여 부사관으로 임관했고,  
'무엇이든 1등이 되고 싶다'는 열망으로 각종 교육에서 1등으로 수료하며 목표 달성을 위한 열정과 성실함을 증명했습니다.  
UN 평화유지활동의 일환으로 레바논 파병 임무까지 수행하며, 강인한 체력과 인내심은 물론 계획적이고 체계적인 업무 능력을 키웠습니다.  
극한의 상황에서도 임무를 완수한 경험은 저의 끈기와 문제 해결 역량을 더욱 성장시켰습니다.  
전역 후 한국정보통신기술협회(TTA)에서 2년간 파견직으로 근무하며 행정 및 사업관리 업무를 담당했고,  
반복되는 업무를 자동화하는 프로그램을 직접 개발해 적용하면서 데이터 분석이라는 새로운 분야에 매력을 느끼게 되었습니다.  
현재는 Python, SQL을 중심으로 데이터 분석 역량을 키워왔으며, **프로그래머스 데이터 분석 데브코스**(2025.03-2025.07)를 수료하며 실무형 프로젝트 경험과 머신러닝 기초 역량을 체계적으로 갖추었습니다.  
앞으로도 긍정적인 태도와 끈기 있는 학습 자세로 데이터 기반 의사결정에 기여하는 분석가로 성장하겠습니다.
