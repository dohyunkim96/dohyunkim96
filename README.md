# 👋 Why? 를 놓지 않는 분석가, 집요한 데이터 분석가 김도현입니다.

> 📌 **현재 데이터 분석가 포지션을 적극적으로 구직 중입니다.**

## 📝 자기소개
**“틀렸다고 멈추지 않습니다. 왜 틀렸는지를 집요하게 파고듭니다.”**  
저는 **문제의 본질을 “왜?”라는 질문으로 끝까지 추적하는 데이터 분석가 김도현**입니다.  
한국정보통신기술협회 근무 당시 반복 입력·검증 과정을 Python Autogui로 자동화하여 **업무 효율을 7일 → 1시간으로 혁신적으로 개선**했습니다.  
더 나아가 인건비·사업비 증빙과 연구비 카드 내역 등 다양한 **재무 데이터를 분석·관리하며 업무 전반의 투명성과 신뢰성을 확보**했습니다.  
특전사와 UN 파병 경험으로 어떤 환경에서도 끝까지 해내는 **끈기와 도전 정신**을 길렀고, 현재는 Python, SQL, Tableau를 활용해 데이터를 분석하며,  
**데이터로 문제를 정의하고 해답을 제시하는 역량**을 키워가고 있습니다.

## 🔥 주요 프로젝트

- (개인)[재고 현황표를 의사결정 시스템으로 전환한 실무형 데이터 분석 프로젝트](https://github.com/dohyunkim96/genico-inventory-analysis)  (재고 부족 우선순위 판단 기준 설계 및 핵심 품목 도출)
  - 물류창고 재고 데이터를 기반으로 일일소비량·7일소비량·안전재고 등 파생변수 설계 후,  
재고 상태(긴급/주의/정상) 및 위험점수 모델을 구축하여 품목별 리스크를 정량화.
  - 재고 커버리지, 소비 급증률 등을 반영한 **위험등급 체계(즉시처리/우선처리 등)**를 정의하고,  
긴급 발생 비율 및 반복 패턴 분석을 통해 발주 및 재고 운영 의사결정 개선 방향 제시.

- (팀)[카드사 고객 세분화를 통한 수익 모델 최적화](https://github.com/dohyunkim96/credit-clustering) (KMeans 기반 고객 세그먼트 분석 및 군집별 마케팅 전략 수립 / ROI 분석)  
  - 고객의 소비·소득·신용 데이터를 기반으로 UMAP+KMeans **클러스터링을 수행하여 5개 고객군 도출**,  
각 군집별 맞춤형 **마케팅 전략 및 ROI 분석** 진행.  
  - ‘초고위험 부채군’에는 리스크 완화 전략, ‘프리미엄 고객군’에는 고급 프로모션 전략을 제시하여  
    수익률 +9.8%p, 최대 ROI +62.9%의 개선 효과 도출.

- (개인)[무인판매점 매출 분석 대시보드](https://github.com/dohyunkim96/unmanned-store-dashboard)  
  - 2025년 3~7월 무인판매점 매출 데이터를 분석하고 **Tableau 대시보드 제작**  
  - 커피(53.4%) + 라면(30.7%) → 매출의 84% 차지 **[👉 Tableau 대시보드 체험하기](https://public.tableau.com/app/profile/.87511212/viz/1__17560918715200/1)**
 
- (개인)[A사 부진 재고 분석](https://github.com/dohyunkim96/Slow-moving-Inventory-Classification-and-Logic-Development)(재고 회전율 기반 부진 재고 분류 로직 개발)
  - 3개월간의 판매·재고 데이터를 활용해 재고 회전율·소진율 등 핵심 지표 산출, 부진·관심·정상 재고로 자동 분류하는 로직 개발.
  - 전체 재고의 **약 25%** 가 부진 재고로 분류되었으며, 부진은 **AP·KIDS·WOMENS** 등 특정 제품군에 집중됨.

- (팀)[S&P 500 지수 방향성 예측](https://github.com/dohyunkim96/sp500-direction-prediction) (시계열 경제지표 및 기술적 지표를 활용한 머신러닝 분류 모델 개발)  
  - 경제지표 및 금융자산 데이터를 활용해 S&P500의 단기 상승 여부(0.2% 이상)를 예측하는 Random Forest 모델을 개발하였으며,  
    **AUC 0.94, F1 Score 0.87**의 성능을 달성. 
  - 시계열 분할, 파생 변수 생성(30여 종), SMOTE 등 전처리 및 성능 개선에 주도적으로 기여함.
